# Changelog

## v1.0.0 — 2026-10-25

Первый открытый релиз.

### Возможности
- Telegram-бот на aiogram 3: регистрация профиля (факультет и курс), персонализированная выдача ответов.
- Нечёткий поиск по базе знаний (RapidFuzz: token set / partial / token sort) с расширением запроса синонимами («общага» → «общежитие»), топ-5 результатов и кнопки «похожие вопросы».
- Контакты служб по категориям и «карта действий» для типовых ситуаций; постоянное меню.
- SQLite (aiosqlite): таблицы `users`, `faq`, `contacts`; демо-данные в `seed_data.py`.
- Парсеры сайта Финансового университета (`parsers/`): скачивание страниц, извлечение FAQ по шаблонам, опциональный анализ через Anthropic API. Скачанные данные в репозиторий не входят.
- Docker / docker-compose: БД в именованном томе, автозаполнение демо-данными при первом запуске.
- Тесты (pytest) и GitHub Actions CI.

### Что вошло в подготовку релиза
- Ad-hoc скрипты и отчёты о ходе работы (FINAL_REPORT, PARSING_REPORT, CHECKLIST и т.п.) убраны из репозитория; полезное сведено в `docs/`.
- Исправлен `docker-compose.yml`: монтирование несуществующего файла БД создавало каталог — теперь именованный том.
- Токены в документации заменены плейсхолдерами; добавлен `.env.example`.

### Известные ограничения
- Бот не является официальным продуктом Финансового университета.
- Рабочая база знаний (≈150 FAQ, собранных с сайта университета) не публикуется; в репозитории — небольшой демонстрационный набор.
- Для `parsers/analyze_fa_pages.py` нужен пакет `anthropic`, он не входит в `requirements.txt`.
