# Парсер сайта FA.RU

## Описание
Автоматический парсер сайта Финансового университета (fa.ru), который собирает:
- FAQ и часто задаваемые вопросы
- Контактную информацию (телефоны, email)
- Информацию для студентов

## Использование

### Базовый запуск
```bash
python -m parsers.parse_fa_ru
```

### Настройки в коде

```python
parser = FAParser()
parser.max_pages = 50  # Количество страниц для парсинга (по умолчанию 100)
```

### Приоритетные разделы
Парсер в первую очередь обрабатывает:
- `/studentu/` - Информация для студентов
- `/abiturientu/` - Информация для абитуриентов
- `/contacts/` - Контакты
- `/about/` - О университете
- `/education/` - Образование

## Результаты

Данные автоматически добавляются в `finguide.db`

## Категории FAQ
Парсер автоматически определяет категории:
- Стипендии
- Общежитие
- Библиотека
- Документы
- Учебный процесс
- Поступление
- Контакты
- Общие вопросы

## Алгоритм работы

1. **Обход страниц**: Начинает с главной и приоритетных разделов
2. **Извлечение FAQ**: Ищет паттерны вопрос-ответ (заголовки + текст)
3. **Извлечение контактов**: Находит телефоны и email через регулярные выражения
4. **Категоризация**: Автоматически определяет категорию по ключевым словам
5. **Сохранение**: Записывает в JSON и базу данных

## Ограничения

- Максимум страниц: настраивается через `max_pages`
- Timeout запросов: 10 секунд
- Длина ответа: до 1000 символов
- Только внутренние ссылки fa.ru

## Расширение

### Добавить новые приоритетные разделы
```python
parser.priority_sections.append('/new-section/')
```

### Изменить паттерны поиска
Отредактируйте методы:
- `extract_faq()` - для FAQ
- `extract_contacts()` - для контактов
- `detect_category()` - для категорий

## Примеры использования

### Парсинг только определённых разделов
```python
parser = FAParser()
parser.priority_sections = ['/studentu/']
parser.max_pages = 20
await parser.start_parsing()
```

### Сохранение только в JSON
```python
await parser.start_parsing()
parser.save_to_json('my_data.json')
# Не вызываем save_to_database()
```

## Troubleshooting

**Проблема**: Парсер не находит FAQ  
**Решение**: Проверьте HTML структуру сайта, возможно изменились классы/теги

**Проблема**: Слишком долго работает  
**Решение**: Уменьшите `max_pages` или ограничьте `priority_sections`

**Проблема**: Дубликаты в базе  
**Решение**: Очистите базу перед парсингом или добавьте проверку на уникальность

## Двухэтапный парсинг FA.RU с анализом Claude

## Концепция

Вместо простого парсинга HTML, мы:
1. **Этап 1:** Скачиваем все страницы в текстовые файлы
2. **Этап 2:** Claude анализирует каждую страницу и создаёт качественные FAQ

## Преимущества

✅ **Качество:** Claude понимает контекст и создаёт развёрнутые ответы  
✅ **Глубина:** Ответы до 500 слов вместо 150 символов  
✅ **Точность:** Правильная категоризация и извлечение ключевых слов  
✅ **Гибкость:** Можно переанализировать страницы без повторного скачивания  

## Этап 1: Скачивание страниц

```bash
python -m parsers.download_fa_pages
```

**Что делает:**
- Скачивает до 500 страниц с fa.ru
- Сохраняет HTML в `data/fa_pages/html/`
- Извлекает текст в `data/fa_pages/text/`
- Создаёт индекс `data/fa_pages/index.json`

**Время:** ~15-20 минут  
**Результат:** 500 текстовых файлов

## Этап 2: Анализ с Claude

```bash
# Установить API ключ
export ANTHROPIC_API_KEY=sk-ant-...

# Запустить анализ
python -m parsers.analyze_fa_pages
```

**Что делает:**
- Читает каждый текстовый файл
- Отправляет Claude для анализа
- Извлекает FAQ с развёрнутыми ответами
- Извлекает контакты с полной информацией
- Сохраняет в `data/analyzed_faq.json`

**Время:** ~30-60 минут (зависит от количества страниц)  
**Результат:** Качественные FAQ с глубокими ответами

## Сравнение подходов

### Старый подход (regex парсинг):
- Ответы: 150 символов
- Качество: среднее
- Категории: автоматические (по ключевым словам)
- Результат: 38 FAQ

### Новый подход (Claude анализ):
- Ответы: до 500 слов
- Качество: высокое (понимание контекста)
- Категории: точные (понимание смысла)
- Результат: 200-500 FAQ (ожидается)

## Пример улучшения

**Было (regex):**
```
Q: Как получить стипендию?
A: Стипендия назначается студентам, сдавшим сессию без троек...
```

**Стало (Claude):**
```
Q: Как получить стипендию в Финансовом университете?
A: Стипендия в Финансовом университете назначается студентам 
по результатам сессии. Для получения базовой стипендии необходимо 
сдать все экзамены и зачёты без троек. 

Повышенная стипендия назначается при средней оценке 4.5 и выше, 
а также за достижения в научной, спортивной и общественной 
деятельности.

Выплаты производятся до 25 числа каждого месяца на банковскую 
карту, указанную при зачислении. Если 25-е число выпадает на 
выходной, выплата производится в предыдущий рабочий день.

Для получения социальной стипендии необходимо предоставить 
справку из органов социальной защиты. Размер социальной стипендии 
не зависит от успеваемости.

Дополнительная информация: dekanat@fa.ru, +7 (495) 123-45-67
```

## Использование

### Запуск полного цикла:
```bash
# 1. Скачать страницы
python -m parsers.download_fa_pages

# 2. Установить API ключ
export ANTHROPIC_API_KEY=sk-ant-...

# 3. Анализировать
python -m parsers.analyze_fa_pages

# 4. Результат автоматически сохранится в базу
```

### Переанализ без повторного скачивания:
```bash
# Если страницы уже скачаны, можно просто переанализировать
python -m parsers.analyze_fa_pages
```

### Настройки:

**download_fa_pages.py:**
```python
downloader.max_pages = 500  # Количество страниц
```

**analyze_fa_pages.py:**
```python
# Модель Claude (можно изменить)
model="claude-sonnet-4-20250514"

# Длина ответа
max_tokens=4000
```

## Стоимость

Claude Sonnet 4:
- Input: $3 / 1M tokens
- Output: $15 / 1M tokens

Примерная стоимость для 500 страниц:
- Input: ~2M tokens = $6
- Output: ~500K tokens = $7.5
- **Итого: ~$13-15**

## Troubleshooting

**Ошибка: ANTHROPIC_API_KEY not set**
```bash
export ANTHROPIC_API_KEY=sk-ant-your-key
```

**Ошибка: Rate limit**
- Добавить задержку между запросами
- Уменьшить количество страниц

**Ошибка: JSON parse error**
- Claude иногда возвращает текст вместо JSON
- Скрипт автоматически ищет JSON в ответе
