## 🛠️ ИНСТРУМЕНТЫ И СКРИПТЫ

### Парсеры
1. **download_fa_pages.py** - Загрузчик страниц
   - Лимит: 10000 страниц
   - Глубина рекурсии: 20
   - Пропускает уже скачанные
   - Защита от бесконечной рекурсии

2. **rebuild_index.py** - Восстановление индекса
   - Читает все текстовые файлы
   - Извлекает URL из первой строки
   - Создает корректный index.json

3. **quick_analyze.py** - Быстрый анализатор
   - Pattern-based извлечение FAQ
   - Без API, работает локально
   - Категоризация автоматическая

4. **analyze_fa_pages.py** - Claude анализатор
   - Использует Anthropic API
   - Создает развернутые ответы (до 500 слов)
   - Требует API ключ (не запущен)

### Утилиты
5. **show_db.py** - Просмотр базы данных
6. **fix_database.py** - Пересоздание БД с UTF-8
7. **start_bot.bat** - Запуск бота (исправлен)

## 🔧 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ

### Стек технологий:
- **Python 3.12**
- **aiogram 3.7** (Telegram Bot API)
- **SQLite** (база данных)
- **aiosqlite** (async SQLite)
- **RapidFuzz** (fuzzy search)

- **aiohttp** (async HTTP)

